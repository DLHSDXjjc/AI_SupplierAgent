供应商管理指南

一、供应商评估维度

选择供应商时，应从以下六个维度进行综合评估：

1. 质量维度（权重30%）
   - 产品合格率：批次合格率应达到98%以上
   - 质量一致性：不同批次产品质量的稳定程度
   - 质量改进能力：出现质量问题后的改进速度和效果
   - 质量认证：是否通过ISO9001等行业质量认证

2. 交期维度（权重25%）
   - 准时交货率：应达到95%以上
   - 交期稳定性：实际交期与承诺交期的偏差
   - 加急响应能力：紧急订单的响应速度
   - 交期透明度：能否提供订单实时追踪

3. 成本维度（权重20%）
   - 价格竞争力：与市场均价的对比
   - 价格稳定性：价格波动的频率和幅度
   - 付款条件：账期、折扣等优惠条件
   - 总拥有成本：包括采购、运输、检验等全部成本

4. 服务维度（权重10%）
   - 响应速度：询价和问题反馈的响应时间
   - 技术支持：技术问题的解决能力
   - 售后服务：退换货、质量问题的处理效率
   - 协作意愿：配合改进和定制的意愿

5. 供应能力维度（权重10%）
   - 产能余量：是否具备应对需求增长的产能
   - 财务状况：财务健康度，是否存在经营风险
   - 原材料来源：原材料供应是否稳定
   - 备用产能：突发情况下能否快速扩产

6. 合规维度（权重5%）
   - 环保合规：是否符合环保法规要求
   - 劳工权益：是否遵守劳动法规
   - 知识产权：是否存在侵权风险
   - 商业信誉：行业口碑和法律纠纷情况

二、交期管理

交期（Lead Time）是从下单到货物入库的总时间，包括：
- 订单处理时间：1-2个工作日
- 生产/备货时间：根据商品类型3-30天不等
- 运输时间：1-7天（取决于距离和运输方式）
- 来料检验时间：1-3个工作日
- 入库上架时间：0.5-1个工作日

缩短交期的方法：
1. 与供应商签订框架协议，减少单次下单的审批时间
2. 建立供应商库存（VMI），供应商在需方仓库备货
3. 选择距离较近的供应商，缩短运输时间
4. 建立快速检验通道，对优质供应商实行免检或抽检
5. 采用电子化订单系统，减少人工处理环节

交期异常处理：
1. 供应商延迟交货时，立即启动催交流程
2. 超过承诺交期3天，通知采购主管
3. 超过承诺交期7天，启动备用供应商
4. 每月统计各供应商交期表现，纳入供应商考核

三、多供应商策略

对于关键物料，应建立多供应商策略，降低单一供应商风险：

1. 主供应商（占采购量60-70%）
   - 价格最优，质量最稳定
   - 适合常规采购和大批量采购

2. 备用供应商（占采购量20-30%）
   - 保持定期采购，维持合作关系
   - 主供应商出问题时可快速切换

3. 紧急供应商（占采购量0-10%）
   - 交期最短，但价格较高
   - 仅在紧急情况下使用

多供应商管理的注意事项：
- 避免过度分散，每个品类供应商数量控制在2-4家
- 定期比较各供应商的综合表现
- 向主供应商承诺最低采购量，争取更优条件
- 保持与所有供应商的信息沟通

四、紧急采购流程

当出现以下情况时，启动紧急采购：
1. 突发需求激增，现有库存无法满足
2. 主供应商断供（停产、破产、不可抗力等）
3. 库存盘点发现重大盘亏
4. 质量问题导致大批退货

紧急采购流程：
1. 需求部门提交紧急采购申请，注明紧急原因和最晚到货时间
2. 采购经理审批（紧急情况下可先口头审批，事后补流程）
3. 优先联系已有备用供应商，协商加急交货
4. 如备用供应商无法满足，寻找新供应商
5. 紧急采购可适当放宽价格审批权限，但需事后说明
6. 货物到达后优先检验、优先入库
7. 紧急采购完成后，进行复盘，分析原因并制定预防措施

五、供应商分级管理

根据综合评估结果，将供应商分为四个等级：

战略级供应商：
- 综合评分90分以上
- 供应关键物料，合作关系深厚
- 享受优先付款、长期合同等优惠
- 每季度高层互访，共同制定发展计划
- 可参与新产品研发，提前了解需求变化

优选级供应商：
- 综合评分80-89分
- 供应重要物料，质量和服务良好
- 享受较优付款条件
- 每半年进行一次综合评审
- 有机会升级为战略级供应商

合格级供应商：
- 综合评分70-79分
- 供应一般物料，满足基本要求
- 标准付款条件
- 每年进行一次综合评审
- 存在改进空间，需定期跟进

淘汰级供应商：
- 综合评分低于70分
- 存在严重质量问题或交期问题
- 限制新业务分配
- 给出3个月改进期限
- 改进不达标则终止合作

六、供应商绩效考核

每月对供应商进行绩效考核，考核指标：

1. 准时交货率 = 准时交货批次 / 总交货批次 × 100%
2. 质量合格率 = 合格批次 / 总检验批次 × 100%
3. 响应及时率 = 24小时内回复的询价次数 / 总询价次数 × 100%
4. 退货处理率 = 按时完成退换货的次数 / 总退换货次数 × 100%

考核结果应用：
- 连续3个月评分下降，发出改进通知
- 连续6个月评为优秀，可升级供应商等级
- 年度考核不合格，列入淘汰观察名单
